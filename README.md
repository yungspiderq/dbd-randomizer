# DBD Ultimate Search Randomizer

Случайный генератор билдов для Dead by Daylight (выжившие и маньяки) с авто-экипировкой через поиск в инвентаре.

## Возможности
- 🎲 Рандомизация билдов: персонаж, сила/предмет, 2 аддона, 4 перка
- 🎭 Отметка доступных персонажей (чекбоксы, сохраняются в конфиг)
- 🎯 Настройка координат кликов для вашего разрешения экрана
- ⚡ Авто-экипировка: открывает слот → вставляет название в поиск → выбирает результат

## Установка

**Способ 1 — самый простой (Windows):** скачайте ZIP репозитория (Code → Download ZIP), распакуйте и запустите `install.bat` — он сам установит зависимости и откроет программу. Дальше запускайте `run.bat`.

**Способ 2 — через pip:**
```bash
pip install -r requirements.txt
python dbd_randomizer.py
```
или установка как пакета (появится команда `dbd-randomizer`):
```bash
pip install .
dbd-randomizer
```

**Способ 3 — одной командой с GitHub:**
```bash
pip install git+https://github.com/yungspiderq/dbd-randomizer.git
dbd-randomizer
```

Windows + Python 3.8+. Требуется окно игры на том же мониторе/разрешении, что и настройки координат.

## Авто-обновление 🔄
Программа сама проверяет новые релизы на GitHub при запуске и каждые 30 минут.
При обнаружении обновления покажет окно с описанием изменений и кнопкой
**«Обновить и перезапустить»** — новый `dbd_randomizer.py` скачается поверх текущего и приложение перезапустится.
Отключить автопроверку: вкладка **НАСТРОЙКА КЛИКОВ** → блок «АВТО-ОБНОВЛЕНИЕ» (кнопка «Проверить обновления сейчас» работает всегда).

## Первый запуск
1. Вкладка **ПЕРСОНАЖИ** — отметьте открытых персонажей → Сохранить
2. Вкладка **НАСТРОЙКА КЛИКОВ** — укажите координаты слотов и поиска (🎯 Указать кликом) → Сохранить
3. Вкладка **РАНДОМАЙЗЕР** — Сгенерировать билд → переключитесь в меню снаряжения игры → Запустить экипировку

Конфиг: `dbd_randomizer_config.txt`
