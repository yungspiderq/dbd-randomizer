# DBD Ultimate Search Randomizer — Qt Beta 14

Современная Windows-версия рандомизатора Dead by Daylight на **PySide6 / Qt Quick**.

## Beta 14 — Visual Polish

- Общие карточки персонажей и героев галереи скинов; портреты, выделение активного элемента, векторные индикаторы и единое оформление.
- Улучшенная подсветка наборов внешности, избранных билдов и карточек перков.
- Тема **Crimson / Frost / Violet** применяется к большинству карточек, кнопок, каталогов и миниатюр.
- Плавные состояния наведения, поддержка отключения анимаций и масштаба 90–120% из Beta 13.
- Сохранены разделение выживших и маньяков, изображения скинов, поиск, коллекции, закрепление перков, ротация, статистика и автоэкипировка.

## Установка

Из установленной **Qt Beta 13** используйте «Проверить обновления». При ручной установке загрузите **`DBDRandomizerQtBeta.zip`** из GitHub Releases, полностью извлеките папку `DBDRandomizerQtBeta` и запустите EXE внутри неё. Папка `_internal` необходима для Python DLL и Qt.

Рекомендуется сделать резервную копию `dbd_randomizer_config.json` перед установкой. Автообновление проверяет SHA-256 и не заменяет JSON-файлы пользователя.

Исходники (Python 3.12+):

```powershell
py -m pip install -r qml_preview/requirements.txt
py qml_preview/main.py
```

CI на Windows тестирует загрузку реального Qt-окна и каталогов, логику перков/аддонов, сохранение избранного, portable EXE и целостность ZIP. Для автоматических кликов в живой игре рекомендуется предварительный сухой прогон и F9.
