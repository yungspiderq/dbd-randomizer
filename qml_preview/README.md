# DBD Randomizer — Qt Beta 10

Самостоятельный современный интерфейс PySide6 / Qt Quick к оригинальным игровым базам и генератору DBD Randomizer.

## Новое
- Оптимизирована загрузка изображений: **до трёх параллельных загрузчиков** и очередь без дублированных запросов.
- Значительно сокращён набор упаковываемых библиотек Qt, без отказа от однофайлового EXE и механизма обновлений.
- **Статистика за сегодня, 7 дней, 30 дней и всё время**, для маньяков/выживших, персонажей, перков, аддонов и предметов.
- Общие данные Beta 9 сохранены; новая ежедневная аналитика начинается с Beta 10.
- Сохранены галерея персонажей и скинов, крупные карточки и фиксация перков, сбалансированная ротация, конструктор, справки и автоматизация.

## Установка на Windows
Скачать `DBDRandomizerQtBeta.exe` из GitHub Releases, предварительно сохранив резервную копию `dbd_randomizer_config.json`.

Запуск из Python 3.12+:
```powershell
py -m pip install -r qml_preview/requirements.txt
py qml_preview/main.py
```

## Проверки
Windows CI тестирует:
- ежедневные счётчики и сохранение старой статистики;
- отсутствие разрастания потоков при большом количестве иконок;
- запуск Qt QML и упакованного EXE;
- размер EXE в сравнении с Beta 9.

Первый запуск упакованного EXE может оставаться медленнее последующих. Внутриигровую автоэкипировку сначала проверяйте в сухом прогоне, F9 должен останавливать процесс.
