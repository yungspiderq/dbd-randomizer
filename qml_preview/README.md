# DBD Ultimate Search Randomizer — Qt Beta 16

Windows-версия рандомизатора Dead by Daylight на **PySide6 / Qt Quick**.

## Конструктор билдов

- Четыре визуальных слота с миниатюрами, выбором по клику и удалением перков.
- Исправлен перенос из каталога в слот, перестановка занятых слотов и отмена переноса вне области слотов.
- Поиск по перку или персонажу, фильтры «Все / Общие / Уникальные / Персонажа».
- Выбор навыков только подходящей стороны, защита от дубликатов и строгая проверка пользовательских сборок.

## Beta 16 — безопасность и стабильность

- Исправлено определение текущей версии обновления.
- При неудачном вводе автоэкипировка останавливается, а неподтверждённая конфигурация не записывается как достоверная.
- Защита от повторного запуска автоматизации, новые регрессионные тесты.
- Сохранены темы Crimson / Frost / Violet, избранное, статистика, ротация, скины и аддоны.

## Установка

После публикации Beta 16 можно обновиться через «Проверить обновления» из Beta 15. При ручной установке скачайте ZIP из GitHub Releases, полностью распакуйте его и запускайте EXE вместе с папкой `_internal`.

Перед обновлением рекомендуется резервная копия `dbd_randomizer_config.json`.

Исходники (Python 3.12+):

```powershell
py -m pip install -r qml_preview/requirements.txt
py qml_preview/main.py
```

Windows CI проверяет backend, реальные взаимодействия с конструктором в Qt offscreen, portable EXE и ZIP. Автоэкипировку сначала запускайте в сухом прогоне. F9 останавливает выполнение.

## Проверки автоэкипировки (этап 3)

Перед каждым вводом проверяется фокус окна Dead by Daylight. При потере фокуса автоматизация прекращается; она не возвращает окно игры автоматически. Если включена OCR-проверка, необходимо настроить область OCR: пустое распознавание не считается успешным поиском. OCR проверяет видимый текст, **но не гарантирует, что навык действительно экипирован**. Сначала выполните сухой прогон. Стоп — назначенная клавиша (по умолчанию F9) или кнопка интерфейса.

## Qt UI performance (этап 4)

- Загрузка серии изображений вызывает не больше одного обновления каталога за короткий интервал (120 мс), вместо перерисовки после каждой иконки.
- Миниатюры загружаются с ограничением размера декодирования до 2× видимого разрешения.
- Прокручиваемые списки переиспользуют карточки (`reuseItems`) и небольшой буфер предварительной отрисовки.
- Каталоги персонажей и избранного повторно используют результаты выборки, не вызывая бэкенд несколько раз за один цикл QML.
- Поиск в избранном и галерее внешности обновляется после короткой паузы ввода (160 мс).
- Windows CI проверяет изменение размеров окна и масштабирование интерфейса.

## Если автообновление зависло на Beta 12

В Beta 12–15 на экране был зафиксирован текст `v2.28.0-qt-beta.12`, даже если EXE фактически обновился. Если версия не изменилась и по содержимому приложения, проверьте `dbd_update_error.log` в папке с EXE. В Beta 16 установщик дополнительно ведёт `dbd_update_progress.log` и показывает последнюю ошибку внутри приложения.

Для однократного ручного обновления остановите программу, сделайте резервную копию пользовательских JSON-файлов и целиком распакуйте новый portable ZIP в **отдельную папку**; запускайте EXE рядом с `_internal`. Автоматический механизм старой Beta 12 невозможно исправить без замены её файлов.
