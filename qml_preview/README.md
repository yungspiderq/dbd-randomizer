# DBD Randomizer Qt Beta 8

Qt Quick интерфейс на PySide6 для существующего движка DBD Randomizer. Qt-версия не требует скрытого Tkinter-окна и использует настоящие базы персонажей, перков, аддонов и внешности.

## Новое в Beta 8: Build Experience

- Большие перк-карточки с анимацией появления при генерации; реальные иконки загружаются по мере надобности в локальный кэш.
- Информация о перке в отдельном модальном окне: имя, тип, персонаж-источник, ссылка на справочник. Неподтверждённые описания не показываются.
- Быстрое закрепление/открепление каждого слота и всех четырёх сразу, счётчик фиксаций.
- **Закрепления переживают полную генерацию** в пределах одной стороны; не допускаются дубликаты и нарушение ограничений челленджей и белых списков навыков.
- Одна кнопка для переброса незакреплённых навыков.
- Прежние функции — сбалансированная ротация, галереи персонажей и скинов, подробные аддоны и челленджи, конструктор, автоэкипировка и обновления — сохранены.

## Запуск

Windows: скачайте `DBDRandomizerQtBeta.exe` из GitHub Releases и положите рядом с прежним `dbd_randomizer_config.json`. Сохраните резервную копию папки.

Исходники (Python 3.12+):
```powershell
py -m pip install -r qml_preview/requirements.txt
py qml_preview/main.py
```

F5 — генерация (с учётом фиксаций), F6 — копировать, F9 — остановить автоматизацию.

## Примечания

Проверки CI автоматические; запуск и работу автоэкипировки в настоящем игровом меню нужно дополнительно проверить на пользовательском компьютере. Описания перков пока отсутствуют в базе проекта; окно «Подробнее» показывает точную принадлежность и ссылку на актуальный справочник.
