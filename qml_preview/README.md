# DBD Ultimate Search Randomizer — Qt Beta 15

Современная Windows-версия рандомизатора Dead by Daylight на **PySide6 / Qt Quick**.

## Beta 15 — Build Creator 2.0

- Конструктор: четыре визуальных слота с миниатюрами, выделением и удалением навыков.
- Перетаскивание навыков из каталога в слот и обмен заполненных слотов местами. Выбор по клику тоже работает.
- Каталог: поиск по имени навыка и персонажу-владельцу; фильтры «Все / Общие / Уникальные / Персонажа».
- Реальные навыки выбранной стороны, без дубликатов. Прежняя проверка пользовательских сборок и формат настроек сохранены.
- Без изменений: Crimson / Frost / Violet, избранное, статистика, ротация, скины, аддоны и автоэкипировка.

## Установка

После публикации Beta 15 из **Qt Beta 14** можно обновиться через «Проверить обновления». При ручной установке скачайте `DBDRandomizerQtBeta.zip` из GitHub Releases, полностью распакуйте его и запускайте EXE рядом с папкой `_internal`.

Перед обновлением рекомендуется сделать резервную копию `dbd_randomizer_config.json`.

Исходники (Python 3.12+):

```powershell
py -m pip install -r qml_preview/requirements.txt
py qml_preview/main.py
```

Windows CI проверяет backend и QML, включая открытие конструктора, а затем portable EXE и ZIP. Для взаимодействия с игровым меню сначала рекомендуется сухой прогон; остановка F9.
