# DBD Randomizer Qt Beta 9

Современный интерфейс на **PySide6 + Qt Quick (QML)**, использующий оригинальный генератор Dead by Daylight.

## Новое — статистика

Вкладка «Статистика» показывает и сохраняет историю выпадений в **обоих режимах рандомизации**:
- отдельно для маньяков и выживших;
- частые/редкие/давно не выпадавшие персонажи, навыки, аддоны и предметы;
- горизонтальные графики, сводные счётчики и 100 последних событий;
- копирование отчёта и отдельный сброс статистики с подтверждением.

История записывается с версии **Beta 9**. Ранее существовавшие счётчики сбалансированной ротации сохраняются отдельно и продолжают работать. Очистка новой статистики на них не влияет.

Кроме этого в программе остались галереи персонажей и скинов, большие карточки перков, закрепления при полной перегенерации, конструктор, описание челленджей, справка по аддонам, автоматизация, горячие клавиши и обновления GitHub Releases.

## Windows

Загрузите `DBDRandomizerQtBeta.exe` из официального релиза. Установите рядом с `dbd_randomizer_config.json`, сделав резервную копию папки.

Для запуска из Python 3.12+:
```powershell
py -m pip install -r qml_preview/requirements.txt
py qml_preview/main.py
```

## Ограничения

Тесты CI подтверждают запуск Qt и EXE на Windows, но не корректность кликов в живой игре. Перед автоэкипировкой проверьте координаты и горячую клавишу остановки F9 в режиме сухого прогона.
