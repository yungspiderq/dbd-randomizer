# DBD Randomizer Qt Beta 7

Полноценный Qt Quick frontend (PySide6 + QML), использующий оригинальные игровые базы и генератор DBD Randomizer, без скрытого окна Tkinter.

## Что есть

- Тёмный интерфейс с настраиваемым изображением иконки в EXE, окне, панели задач и боковом меню.
- Генерация по обычной случайной выборке или с опциональной **сбалансированной ротацией**.
- Ротация учитывает частоту и давность попаданий и отдельно хранит историю маньяков, выживших, перков и аддонов.
- Два списка персонажей с портретами, галерея внешности, описание челленджей, названия и часть проверенных описаний эффектов аддонов.
- Визуальный конструктор, community-билды, сохранение координат, таймингов, сухой прогон, остановка F9.
- Обновления Qt-релизов из GitHub с проверкой SHA-256.

## Иконка

`qml_preview/assets/app_icon.svg` — векторная иконка по умолчанию. Если положить `qml_preview/assets/app_icon_source.png`, скрипт использует **этот PNG** для создания требуемых размеров и EXE-иконки.

```powershell
py -m pip install -r qml_preview/requirements.txt
py qml_preview/build_icon.py
py qml_preview/main.py
```

Сборка Windows в GitHub Actions автоматически создаёт `app_icon.png` и `app_icon.ico`, передаёт ICO в PyInstaller, а PNG упаковывает вместе с QML.

## Ограничения

Выбор с ротацией остаётся случайным: он уменьшает вероятность скорого повтора, но не гарантирует отсутствия повторений или строгой очереди. Режим не влияет на оригинальный классический рандом. Статистика живёт в секции `options.rotation_state` пользовательского `dbd_randomizer_config.json`.

Это предварительная сборка Windows 11. Внутриигровая автоматизация не проходила полноценное ручное тестирование на всех разрешениях; сначала выберите сухой прогон. Первая миграция с Tkinter на Qt требует ручного скачивания EXE.
