# DBD Randomizer — Qt Beta 5

Современная самостоятельная Qt Quick версия DBD Ultimate Search Randomizer (PySide6 + QML) с сохранением оригинальных игровых баз и Python-логики, без скрытого Tkinter-окна.

## Особенности
- Тёмный кастомный интерфейс, иконки, карточки перков и экипировки
- Раздельные маньяки и выжившие, портреты, владение персонажами
- Каталог скинов с настоящими изображениями, фильтрами и коллекцией
- **Именованные аддоны** в карточке билда и окно подробностей при нажатии
- Полные правила, сложность и ограничения челленджей
- **Визуальный конструктор** персонажей, перков, предметов и совместимых аддонов; запрет дублей, четыре слота, явная проверка сборки
- Краткие фактические эффекты некоторых аддонов и категории механик из wiki.gg — без неподтверждённых свойств
- Сохранение настроек, режим сухого прогона, автоэкипировка с возможностью остановки F9
- Проверка и установка будущих Qt-релизов по GitHub Release с SHA-256

## Установка

Windows 11: `DBDRandomizerQtBeta.exe` из GitHub Releases. Поместите рядом со старым `dbd_randomizer_config.json` после резервного копирования.

Исходники (Python 3.12+):
```powershell
py -m pip install -r qml_preview/requirements.txt
py qml_preview/main.py
```

Быстрые клавиши: F5 — сгенерировать, F6 — копировать, F9 — аварийная остановка.

## Источники и ограничения

Картинки wiki.gg и категории аддонов загружаются при наличии интернета и сохраняются в локальном кэше. Справочник для категорий: [Module:Datatable/Loadout](https://deadbydaylight.wiki.gg/wiki/Module:Datatable/Loadout); описания: [Module:Datatable/Loadout/Descriptions](https://deadbydaylight.wiki.gg/wiki/Module:Datatable/Loadout/Descriptions). Точные тексты эффектов пока есть не для всего каталога — лучше следовать ссылке на wiki.gg.

Это предварительный выпуск. Проверки Windows CI не заменяют тесты автоэкипировки в игре. Первый переход с Tkinter EXE на Qt нужно выполнить вручную.
