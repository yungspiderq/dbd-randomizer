# DBD Ultimate Search Randomizer — Qt Beta 13

Современный Windows-интерфейс Qt Quick (PySide6/QML) для генератора Dead by Daylight.

## Новое: настройка интерфейса

Во вкладке **«Оформление»** доступны:
- **Crimson / Frost / Violet** — полноценные тёмные темы с красными, синими и фиолетовыми акцентами;
- масштаб основной рабочей области **90 / 100 / 110 / 120%** с моментальным применением;
- плавная анимация вкладок, кнопок, карточек и возможность её отключить;
- сброс всех визуальных настроек без затрагивания игровых данных.

Настройки хранятся в существующем `dbd_randomizer_config.json` (`options.qt_theme`, `options.qt_scale`, `options.qt_animations`). При первом запуске настройки прежних версий остаются нетронутыми, а оформление по умолчанию — Crimson на 100%.

## Переносимость и обновления

Beta 13 распространяется архивом `DBDRandomizerQtBeta.zip`: нужно **распаковать всю папку** с `DBDRandomizerQtBeta.exe` и `_internal`. Старый `python312.dll` остаётся внутри `_internal` и не распаковывается во временный `_MEI`.

С Beta 12 доступно «Проверить обновления». Установщик обновляет исполняемый файл и runtime после SHA-256, не трогая библиотеку избранного, настройки, координаты, кэш изображений и статистику.

## Запуск из исходников (Python 3.12+)

```powershell
py -m pip install -r qml_preview/requirements.txt
py qml_preview/main.py
```

Windows CI проверяет генерацию, сохранение настроек, 3 палитры, масштабирование и движение интерфейса в Qt QML, рабочий EXE, ZIP и SHA-256. Для игровых автокликов используйте сначала сухой прогон и проверку F9.
