# DBD Randomizer — Qt Beta 1

**Предварительная версия**, новый PySide6 + QML интерфейс поверх существующего движка DBD v2.28.0.

Доступны: генерация билдов по оригинальной базе, роли, режимы навыков, копирование и переброс, перки, аддоны, внешность, челленджи, классы 2v8, белые списки персонажей, тайминги, координаты, чтение билдов сообщества и вызов оригинальной автоэкипировки с F9. Оригинальное окно остаётся доступным для расширенного конструктора и публикации билдов.

**Ограничения:** Qt-интерфейс ещё зависит от скрытого Tkinter-движка. Публикация своих билдов, расширенные функции и часть настроек доступны в окне совместимости. В игре автоэкипировка должна пройти ручную проверку. Сначала попробуйте сухой прогон и проверьте работу F9. Данный выпуск не заменяет стабильную версию.

## Windows

Скачайте DBDRandomizerQtBeta.exe ниже. Для запуска из исходников: `py -m pip install -r qml_preview/requirements.txt` и `py qml_preview/main.py`.
