# DBD Randomizer Qt v3.0.2 Stable — быстрая прокрутка

**Релиз:** `v3.0.2`  
**Канал:** Stable, обновление с v3.0.1.

## Что нового

- Видимые вертикальные полосы прокрутки в длинных разделах. Просто перетащите ползунок мышкой вверх или вниз для быстрого перехода по странице.
- Полосы работают в центральном контенте, боковой навигации, настройках, галерее внешности, списках персонажей, навыков и аддонов, избранном, истории статистики и модальных справочниках.
- На коротких страницах полоса автоматически скрывается; обычная прокрутка колесом мыши по-прежнему работает.
- Контрастный ползунок с подсветкой при наведении и захвате; элементы у правого края списка не должны перекрываться ползунком.

## Совместимость

- Сохранены все функции v3.0.1: карточка выпавшего скина, 320 кратких описаний навыков, генерация, адаптивная ротация и справочники.
- Сборка ZIP/EXE использует те же имена файлов для совместимости обновлятора.
- Windows CI проверяет поведение Qt ScrollBar, запуск приложения, регрессионные тесты, ZIP, SHA-256 и установку поверх опубликованной v3.0.1 с сохранением пользовательских данных.
