# DBD Ultimate Search Randomizer — Qt Beta 15

## Build Creator 2.0

- **Четыре визуальных слота** с изображениями навыков, выделением и кнопкой удаления.
- **Перетаскивание** навыков из каталога в слот и обмен навыков между слотами без дубликатов; выбор по клику остаётся доступным.
- **Фильтры:** все навыки, общие, уникальные и навыки выбранного персонажа.
- **Поиск:** по названию навыка и имени персонажа, рядом с навыком показывается его источник.
- **Совместимость:** прежняя валидация сборок, генератор, сохранения, темы, избранное, ротация и остальные функции не изменены.

## Установка

После публикации Beta 15 можно обновиться из Beta 14 кнопкой «Проверить обновления». Вручную: скачайте `DBDRandomizerQtBeta.zip`, распакуйте целиком и запускайте EXE вместе с `_internal`. Рекомендуется резервная копия настроек.

Windows CI проверяет Qt backend, QML, каталог конструктора, portable EXE и ZIP с SHA-256. Это предварительная версия; автоэкипировку сперва проверяйте в сухом прогоне (остановка F9).
