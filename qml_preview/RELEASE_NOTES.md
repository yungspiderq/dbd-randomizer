# DBD Ultimate Search Randomizer — Qt Beta 20 (candidate)

## Надёжность автоэкипировки
- Сохраняется модель Beta 18/19: ручное переключение на нужное окно после отсчёта, контроль HWND и экстренная остановка F9. **Никакой обязательной проверки EXE DBD нет.**
- Теперь координаты **фактически выбранной иконки результата** (с учётом `result_index` и `result_step`) проверяются на попадание в границы рабочего стола *до* запуска мыши.
- Включённая OCR-проверка без заданной области останавливает подготовку, не начиная отсчёт.
- При изменении билда во время отсчёта автоматизация сохраняет исходную сторону (убийца/выживший) для служебного учёта; не помечает результат как проверенный в игре.
- Добавлены регрессионные тесты для предварительной проверки координат, OCR и изменения билда.

## Qt/QML и производительность
- Пакет сообщений о состоянии и ходе обновления вызывает одно уведомление QML вместо десятков повторных сигналов.
- Генерация и переброс перков больше не заставляют все видимые изображения персонажей/аддонов повторно проверять кэш.
- Кнопки экипировки и обновления визуально блокируются, пока соответствующая операция выполняется.
- Раскладка при изменении размера окна проверяется существующим QML smoke-тестом. Для оценки FPS/задержек на конкретном компьютере нужен ручной тест.

## Обновления и безопасность релиза
- Версия кандидата: `v2.28.0-qt-beta.20`.
- Windows E2E проверяет **опубликованную Beta 19 → кандидат Beta 20**: запуск EXE, замену EXE и `_internal`, сохранение настроек, SHA-256 и очистку временных данных.
- Автоматическая публикация при слиянии отключена: создание GitHub Pre-release разрешено только после отдельного ручного запуска workflow с `publish_prerelease=true`.

**Это не стабильный релиз.** Работа ввода в настоящей Dead by Daylight не подтверждается CI. Перед публикацией стабильной версии необходим ручной тест в игре.
