# DBD Randomizer Qt v3.0.1 Stable — образы и описания навыков

**Релиз:** `v3.0.1`  
**Канал:** Stable, обновление с v3.0.0.

## Исправления интерфейса

- Отдельная карточка **«Выпавший скин»** сразу под персонажем в результате генерации: превью изображения, русский вариант названия, английский оригинал, редкость, тип и ID из каталога скинов.
- Если случайная внешность выключена или у персонажа нет отмеченных скинов, показывается причина отсутствия результата вместо пустой строки.
- **Краткие описания всех 320 навыков**, включённых в текущую базу: 144 навыка убийц и 176 выживших. Подробное окно навыка теперь содержит информацию о его механике, а в каталоге «Конструктора» она доступна при наведении.
- Описания краткие, составлены своими словами, не содержат чисел, меняющихся от патча к патчу. Точные условия и значения сверяйте с игрой/официальной DBD Wiki; изменения игрового баланса могут требовать обновления справочника.

## Совместимость

- Обновление с v3.0.0 через «Проверить обновления», либо скачивание полного портативного ZIP.
- Прежнее имя `DBDRandomizerQtBeta.zip` и исполняемого файла сохранено для совместимости обновлятора.
- Настройки, избранное и отмеченные скины не должны перезаписываться установщиком.
- Windows CI проверяет полноту текстов всех навыков, Qt/QML, запуск EXE, безопасный ZIP, SHA-256 и обновление с v3.0.0 на v3.0.1.
