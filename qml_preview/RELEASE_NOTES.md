# DBD Ultimate Search Randomizer — Qt Beta 10

**Performance Update** — оптимизация загрузки изображений, облегчённая упаковка Qt и статистика за разные периоды.

## Производительность
- **Очередь загрузки иконок:** вместо запуска отдельного потока для каждой картинки используется очередь с максимум тремя рабочими потоками, защитой от повторных запросов и отдельной синхронизацией общей таблицы портретов маньяков.
- Картинки продолжают скачиваться в фоне и сохраняться в прежний локальный `icons_cache`. URL уже загруженных миниатюр кешируются в Qt-backend.
- Для EXE удалено принудительное включение **всех** модулей PySide6; сборка теперь собирает нужные Qt Quick/QML компоненты. GitHub Actions измеряет фактический размер и время проверки запуска готового EXE, а также останавливает релиз, если файл не стал меньше Beta 9 (275 443 744 байта).
- Формат **одного EXE с обновлением из приложения** сохранён. Скорость первого запуска зависит от диска и антивируса, поэтому конкретное ускорение в процентах не гарантируется.

## Новые интервалы статистики
На вкладке «Статистика» появились кнопки **«Всё время», «Сегодня», «7 дней», «30 дней»**. Графики частоты, редкие выпадения, счётчики и история переключаются по выбранному периоду. Список «Давно не выпадали» остаётся за всё время (это указано в интерфейсе).

- Суммарные данные из Beta 9 **сохраняются**. Дата каждого выпадения записывается только **начиная с Beta 10** — прошлые события без даты в периодные графики не включаются.
- Дневные счётчики сохраняются в том же `dbd_randomizer_config.json`, максимум за 400 дат. В старом конфиге никакие данные не удаляются.
- Сброс статистики не трогает сбалансированную ротацию. Статистика продолжает работать в обоих режимах.

## Как установить
Из **Qt Beta 9**: нажать «Проверить обновления» и подтвердить установку после SHA-256. Из старой Tkinter-версии первая установка Qt вручную. Сохраните резервную копию конфигурации.

## Ограничения
Это предварительный релиз. CI проверяет Python-логику, ротацию, очередь иконок, учёт периодов, запуск QML, размер и запуск упакованного Windows EXE. Автоэкипировка в настоящем DBD всё ещё требует ручной проверки; используйте сначала сухой прогон и F9.
