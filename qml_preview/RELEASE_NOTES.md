# DBD Ultimate Search Randomizer — Qt Beta 16

## Stability Fixes — первый этап

- Обновление: исправлен номер текущей версии, добавлена проверка соответствия релизного тега перед сборкой. Приложение больше не должно предлагать собственную версию.
- Автоэкипировка: повторное нажатие «Экипировать» не запускает второй поток.
- Автоэкипировка: неудачные клики и вставка текста не считаются успехом; после двух неудачных попыток выполнение останавливается.
- Автоэкипировка: предполагаемое состояние игрового меню больше не записывается как подтверждённый результат. После выполнения необходимо проверить итог в игре.
- Добавлены регрессионные тесты гонки запуска, ошибочного ввода и сохранённого состояния.

## Совместимость

Вся игровая база, генератор, статистика, избранное и пользовательские настройки остаются прежними. Обновляйтесь после появления подтверждённого Windows ZIP на GitHub Releases. Перед обновлением сохраните копию `dbd_randomizer_config.json`.

Реальную автоэкипировку сначала тестируйте в сухом прогоне. Кнопка F9 останавливает выполнение.
