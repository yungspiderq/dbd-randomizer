# DBD Randomizer Qt v3.2.1 — Terrifier

**Канал:** Stable · **ОС:** Windows

- Ужасающий и Сиенна Шоу добавлены в генератор, конструктор и энциклопедию.
- Шесть навыков с краткими описаниями и картами иконок.
- Все 20 аддонов с русскими названиями, предоставленными пользователем. Английские имена сохранены как ключи справочника; прежние EN-записи мигрируют в RU. Снято временное ограничение автоэкипировки. Реальный ввод в клиенте и загрузка новых иконок ещё требуют проверки.
- Исправлены устаревшие проверки количества навыков и испытаний, которые блокировали выпуск.
- Пять игровых челленджей для нового персонажа.
- Миграция базы с ревизии 3 добавляет новые записи, не перезаписывая существующие ручные правки и списки владения.
- Проверка обновления с v3.2.0.

Портреты и косметика новых персонажей пока не внесены. Русские названия навыков сверены по публикации о PTB, но не по финальному русскому клиенту.
