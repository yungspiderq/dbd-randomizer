# DBD Ultimate Search Randomizer — Qt Release Candidate 2

**Candidate:** `v3.0.0-qt-rc.2`  
**Status:** GitHub testing candidate, не Stable.

## Новые челленджи на способности маньяков

- **132 задания на способности для 44 убийц** из базы (три на каждого — лёгкое, среднее, сложное). У большинства есть два индивидуальных сценария силы и одно тренировочное испытание.
- В разделе настроек челленджей добавлен выбор **«Смешанные» / «Обычные» / «Способности»**. В смешанном режиме у убийц задания на способность появляются примерно в половине генераций; у выживших остаются обычные испытания.
- Испытание силы выбирается **после определения фактически выпавшего маньяка**, в том числе в режиме ротации. Челлендж неподходящего персонажа никогда не выдаётся.
- Карточка показывает маньяка, название способности, точное условие и сложность. Повторный выбор персонального испытания не меняет уже собранные аддоны, перки и персонажа, если новое испытание также персональное.
- Система не получает данные о действиях внутри DBD: выполнение игрок оценивает самостоятельно; автоматические проверки игры не обещаются.

## Исправление аддонов Доктора

- Прежде в базе было только 6 аддонов «Искры Картера», а четыре из них ошибочно считались удалёнными. Поэтому генератор оставлял **только «Радужного короля» и «Радужного ферзя»**.
- Теперь в базе **все 20 игровых аддонов Доктора** с полными русскими названиями, RU→EN-сопоставлениями и корректными иконками.
- Четыре варианта с заметками Картера снова доступны и не проходят через фильтр удалённого контента.
- Ревизия данных поднята до `3`: файл `dbd_database.json` старой ревизии пересоздаётся из новых данных, прежний сохраняется как `.bak`, белые списки владения переносятся и при необходимости обновляются имена.
- Автоматический тест проверяет **300 генераций** Доктора и достижимость всех 20 вариантов.

## Проверки перед Stable

- Windows CI запускает тесты игровых данных, навыков, новых испытаний, Qt/QML и установщика, создаёт EXE+ZIP+SHA-256 и выполняет E2E-установку **опубликованной RC1 → кандидат RC2**.
- Вышедший RC1 не перезаписывается; выпуск RC2 не происходит автоматически.
- Проверки CI не заменяют проверку в реальной игре. До Stable нужно подтвердить обновлённый генератор и персональные испытания на пользовательском ПК.
