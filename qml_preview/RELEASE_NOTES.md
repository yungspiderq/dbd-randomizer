# DBD Randomizer Qt v3.2.3 — поиск и быстрая прокрутка

- При поиске всех навыков и аддонов знаки препинания и другие символы заменяются пробелами, лишние пробелы убираются.
- Официальные названия, иконки, сохранённые билды и списки владения остаются прежними.
- Поиск в Qt-конструкторе, старом интерфейсе и OCR использует нормализацию без пунктуации.
- Прокрутка колёсиком ускорена во всех 15 прокручиваемых областях: один стандартный шаг колеса перемещает содержимое на 240 логических пикселей, с ограничением по краям списка.
- Перетаскивание полосы прокрутки сохранено; задержки автоэкипировки не изменены.
- Добавлены проверки всего каталога и прокрутки. Реальное поведение колеса и поиск в игровом клиенте требуют проверки.
