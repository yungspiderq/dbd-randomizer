# DBD Ultimate Search Randomizer — Qt Release Candidate 1

**Candidate:** `v3.0.0-qt-rc.1`  
**Status:** candidate for real-world testing; **NOT Stable**.

## Основные изменения

- Обновлятор распознаёт старые версии `-qt-beta.N`, новые `-qt-rc.N` и будущие стабильные теги `vMAJOR.MINOR.PATCH`. При одинаковой основной версии порядок корректен: Beta → RC → Stable.
- Подготовлен независимый Windows E2E: установка RC 1 поверх распакованной опубликованной Beta 22, проверка EXE, `_internal`, SHA-256, запуска программы, сохранения настроек, избранного и выбранных обликов.
- Имя portable-архива и EXE **не меняется**, чтобы не ломать установленную структуру и скрипт обновления.
- Добавлены регрессионные тесты обнаружения RC, обнаружения будущей стабильной версии и строгого отклонения неизвестных форматов тегов.
- Добавлен подробный сценарий ручной проверки в DBD: `docs/RC1_TEST_PLAN_RU.md`.

## Ярлык «DBD Randomizer» на рабочем столе

RC1 ZIP теперь содержит `Update DBD Randomizer Shortcut.cmd` и `Repair DBD Randomizer Shortcut.ps1`. После распаковки в постоянную папку откройте **`Update DBD Randomizer Shortcut.cmd` двойным щелчком** — скрипт создаст или исправит ярлык `DBD Randomizer.lnk` на рабочем столе так, чтобы он запускал новый `DBDRandomizerQtBeta.exe`, использовал рабочую папку RC1 и иконку Qt-приложения. Также исправляется существующий одноимённый ярлык в меню «Пуск» текущего пользователя, если он есть. Повышенные права не требуются.

Если RC1 установлен через **новый** встроенный установщик обновления, ярлык исправляется автоматически после успешной замены EXE и `_internal` (ошибка прав доступа к ярлыку не отменяет установку). Из Beta 22 лучше пользоваться ручным ZIP: её старый установщик ещё не содержит такого действия. **Удалённо изменить ярлык на вашем ПК через GitHub нельзя** — нужно запустить CMD локально.

## Важная совместимость

Опубликованная Beta 22 **не умеет автоматически обнаруживать RC-теги**: её обновлятор распознаёт исключительно `-qt-beta.N`. Это известный блокер автоматического перехода по кнопке «Проверить обновления» с Beta 22 на RC 1. Для раннего тестирования используйте RC ZIP **в отдельной папке**, а для массовой миграции требуется совместимый промежуточный релиз.

## Границы подтверждения

- GitHub Windows CI проверяет ZIP и выполняет смоделированный E2E-апгрейд, **не реальную DBD**.
- Работа экипировки четырёх перков, F9, остановки по фокусу и реального обновления на компьютере пользователя должны получить отдельные результаты по чек-листу.
- Непроверенные русские названия внешности, перков и аддонов не объявляются официальными без сверки с клиентом.

Публиковать **Stable v3.0.0** разрешается только после успешных реальных испытаний. Этот кандидат не меняет стабильную ветку `main`.
