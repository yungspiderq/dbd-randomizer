# DBD Ultimate Search Randomizer — Qt Beta 8

**Build Experience Update** — существенная доработка главного экрана и карточек навыков, поверх существующей Qt-версии (PySide6/QML).

## Что нового

- Перерисованы все четыре карточки навыков: крупные настоящие иконки, заметный номер слота, полное название с переносом на две строки, подсветка закреплённого слота, кнопки «Подробнее» и «Переброс».
- **Плавная последовательная анимация** появления карточек после генерации и переброса. Обычное закрепление не запускает анимацию.
- **Подробности по нажатию:** название, тип (общий/уникальный), персонаж-источник из оригинальной игровой базы, крупное изображение, ссылка на справочник перков DBD Wiki. В самой базе приложения пока нет проверенных текстов игровых эффектов перков — их не придумываем.
- **Массовая фиксация:** «Закрепить все навыки», «Снять все закрепления», счётчик закреплённых навыков 0/4.
- **Исправление генерации:** ранее закреплённые перки терялись при генерации нового билда. Теперь они остаются в своих слотах даже при смене персонажа той же стороны, если разрешены действующими ограничениями, а другие перки пересоздаются без дубликатов.
- Если новый челлендж прямо запрещает определённый закреплённый навык или все навыки сразу, соответствующая фиксация снимается автоматически и приложение сообщает об этом.
- Отдельная кнопка переброса всех незакреплённых навыков; копирование и F5/F6 остались.
- Режим сбалансированной ротации из Beta 7 и остальные вкладки сохранены.

## Установка

Qt Beta 7: «Проверить обновления» → Beta 8 → установка с проверкой SHA-256. Старый Tkinter EXE не умеет переходить на Qt автоматически, для него требуется ручная установка из GitHub Releases. Перед обновлением полезно сохранить копию папки с `dbd_randomizer_config.json`.

Это **предварительный релиз**. Windows CI тестирует генерацию, закрепления, ротацию, запуск QML и сборку EXE. Реальные автоклики в игре на разных разрешениях и визуальный QA с человеком ещё требуют проверки; сначала используйте сухой прогон и проверяйте остановку F9.
