# DBD Randomizer Qt v3.2.2 — Terrifier: изображения и справочник

- Добавлены краткие русские описания эффектов всех 20 аддонов Ужасающего.
- Имена файлов 6 навыков, 20 аддонов и силы сверены с таблицей Wiki.
- Сборка пытается получить подтверждённые портреты и наборы одежды K45 / S55 через Wiki API, не меняя существующие ID косметики. Не найденные изображения не подменяются чужими.
- Отчёт проверки файлов публикуется как артефакт GitHub Actions. При недоступности Wiki часть изображений или косметики может остаться недоступной.
- Сохранены названия, предоставленные пользователем, и автоэкипировка.
