# DBD Randomizer Qt v3.1.1 — аудит аддонов и ивентовые предметы

**Канал:** Stable · **ОС:** Windows · **Версия:** `v3.1.1`

## Проверка аддонов

- Каталоги всех 44 маньяков проверяются на дубликаты, игровые RU→EN имена, иконки и возможность выдачи каждого аддона в генераторе. Списки могут иметь различную длину из-за изменений в игре.
- Если режим «Только отмеченные навыки и аддоны» оставил одного-двух доступных аддонов, сообщение объяснит ограничение для любого маньяка, а не только для Доктора.
- При сокращённом локальном каталоге приложение предупреждает об отличии от встроенной базы. Намеренные пользовательские изменения не перезаписываются автоматически; известное восстановление двух радужных аддонов Доктора сохранено.

## Предметы выживших

- Переключатель **«Ивентовые предметы (выжившие)»** доступен на странице генерации и в настройках выжившего. По умолчанию включён.
- При выключении сезонные фонарики, аптечки, ящики с инструментами и хлопушки не участвуют в случайной выдаче. Обычные предметы остаются.
- Флаконы с туманом — стандартный тип предметов, поэтому не исключаются; временный «Туманный кристалл» никогда не выдаётся для экипировки из лобби.
- Фильтр применяется в обычном режиме и сбалансированной ротации, совместим с фильтром «Только отмеченные» и условиями испытаний. Если допустимых предметов нет, отображается пустой слот.
- Настройка сохраняется автоматически без изменения формата пользовательского JSON.

## Проверки и обновление

Windows CI проверяет базу аддонов, ограничения ивентовых предметов, Qt, EXE, ZIP и SHA-256, а также обновление с v3.1.0 без потери настроек.

Из v3.1.0 нажмите «Проверить обновления» либо скачайте полный `DBDRandomizerQtBeta.zip` и распакуйте его целиком.
