# DBD Ultimate Search Randomizer — Qt Beta 11

## Исправление запуска Windows: python312.dll

В Beta 10 при старте однофайлового EXE могла появляться ошибка **Failed to load Python DLL ...\\_MEI...\\python312.dll**. Beta 11 больше не использует временную распаковку PyInstaller `--onefile`.

**Новый формат: portable ZIP** с готовой папкой `DBDRandomizerQtBeta`:
- `DBDRandomizerQtBeta.exe` — запускаемый файл;
- `_internal/python312.dll` и другие зависимости — постоянная папка рядом с EXE;
- все Qt Quick/QML ресурсы включены в комплект.

## Как установить Beta 11 (один раз вручную)

**Из Beta 10, которая показывает ошибку DLL, автоматическое обновление не сработает: программа не может запуститься.**

1. Скачайте **`DBDRandomizerQtBeta.zip`** из этого GitHub Release.
2. В Проводнике Windows нажмите правой кнопкой по ZIP → «Извлечь всё».
3. Откройте извлечённую папку `DBDRandomizerQtBeta` и запускайте **`DBDRandomizerQtBeta.exe` внутри неё**.
4. Если нужно перенести настройки, скопируйте ваш **`dbd_randomizer_config.json`** из папки старой версии в папку рядом с новым EXE. Предварительно сохраните его резервную копию.
5. Не вынимайте EXE из этой папки и не удаляйте `_internal` — теперь это часть приложения.

**Не распаковывайте только EXE** и не пытайтесь заменить им одиночный EXE Beta 10. На Windows иногда требуется актуальная системная **Microsoft Visual C++ Redistributable x64**; если ошибка DLL останется уже в portable-версии, проверьте целостность распаковки и наличие этого компонента.

## Обновления после Beta 11

Обновлятор переделан под ZIP:
- проверяет размер и контрольную сумму SHA-256 релиза;
- безопасно распаковывает все файлы в отдельную временную папку рядом с установленной версией;
- после выхода из приложения заменяет только EXE и папку `_internal`;
- при сбое замены пытается восстановить прежний EXE и зависимости;
- **не меняет** ваши JSON-настройки, базы и кэш изображений;
- автоматически запускает обновлённую версию.

Ранее использованный однофайловый формат отключён. Содержимое ZIP, SHA-256 и первый запуск **готового portable EXE** проверяются Windows GitHub Actions до публикации.

## Остальные функции

Сохранены режим сбалансированной ротации, статистика по периодам, портреты персонажей, галерея внешности, изображения и подписи аддонов, объяснения челленджей, конструктор, закрепления навыков и автоматизация. Внутриигровую автоэкипировку всё ещё рекомендуется сначала проверить в сухом прогоне с F9.

**Примечание:** эта сборка устраняет зависимость от распаковки в `_MEI`, но при отсутствии системных DLL или вмешательстве антивируса возможны отдельные ошибки Windows — нужна диагностика именно того, какого модуля не хватает.
