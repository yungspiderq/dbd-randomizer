# DBD Ultimate Search Randomizer — Qt Beta 23 (RC1 bridge)

**Version:** `v2.28.0-qt-beta.23`  
**Release type:** GitHub **Pre-release**, not Stable.

## Зачем нужна эта версия

Уже опубликованная Beta 22 распознаёт только теги `-qt-beta.N`, поэтому при нажатии «Проверить обновления» она не видит опубликованный RC1 (`v3.0.0-qt-rc.1`). Эта небольшая совместимая Beta 23 устраняет препятствие, не вынуждая всех пользователей вручную скачивать RC1.

## Два простых шага обновления

1. В установленной **Beta 22** нажмите «Проверить обновления» → установите **Beta 23**.
2. В запущенной **Beta 23** нажмите «Проверить обновления» повторно → установите **RC1**.
3. После RC1, если ярлык «DBD Randomizer» остался старым, запустите из новой папки `Update DBD Randomizer Shortcut.cmd`. Он укажет ярлык на Qt-приложение.

Существующие EXE и `_internal` заменяются штатным установщиком; настройки, избранное, история и выбранные скины сохраняются. Как обычно, перед обновлением полезно сделать копию `dbd_randomizer_config.json`.

## Что изменилось

- Сохранена совместимость с предыдущим форматом тегов: старая Beta 22 видит Beta 23.
- Добавлено распознавание будущих версий `-qt-rc.N` и `v3.0.0`. Исторические `v2.x` Stable (старое Tk-приложение) не предлагаются как Qt-обновления.
- Обновлятор не предлагает неполные GitHub Releases без проверяемой суммы SHA-256.
- Не меняется поведение автоэкипировки; **нет проверки имени EXE DBD**.
- Windows CI проверяет переход **опубликованная Beta 22 → кандидат Beta 23** и распознавание реального опубликованного RC1.

**Beta 23 не является Stable.** До стабильного релиза по-прежнему требуется ручная проверка автоэкипировки в самой игре и проверка обновления на пользовательском ПК.
