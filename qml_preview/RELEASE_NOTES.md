# DBD Ultimate Search Randomizer — Qt 3.0.0 Stable

**Релиз:** `v3.0.0`  
**Канал:** Stable — полноценный релиз Windows (Qt Quick / PySide6), не Beta и не Pre-release.

## Что нового

- Полностью переработанный современный интерфейс Qt/QML с темами, избранным, поиском персонажей, скинов и конструктором билдов.
- Режимы обычной генерации и адаптивной ротации, отдельные разделы убийц и выживших.
- **132 персональных испытания на способности 44 убийц**, по три сложности. В настройках: «Смешанные», «Обычные», «Способности». Испытание привязано к фактически выбранному убийце и не требует определённого аддона.
- Корректные карточки заданий с описанием целей. Выполнение испытания отмечается игроком, приложение не считывает события внутри матча.
- Исправлена генерация аддонов **Доктора**: восстановлены все **20** игровых аддонов, названия RU/EN и соответствующие изображения. «Радужный король» и «Радужный ферзь» больше не единственные возможные улучшения.
- При чтении устаревшего `dbd_database.json` восстанавливается известный ошибочный набор из двух радужных аддонов с резервной копией `.doctor-addons.bak`; пользовательские коллекции других убийц не перезаписываются.
- Фильтр теперь честно называется **«Только отмеченные навыки и аддоны»**. Если отмечены только два аддона Доктора, генерация по настройке ограничивается ими. Отключите фильтр или отметьте остальные.
- Исправления автообновления, сохранения конфигурации, ярлыка на рабочем столе и автоэкипировки; F9 останавливает ввод.

## Установка и обновление

1. Скачайте `DBDRandomizerQtBeta.zip` в Assets этого релиза (имя архива сохранено для совместимости старых установщиков).
2. Распакуйте **весь архив** вместе с папкой `_internal`. Запускайте `DBDRandomizerQtBeta.exe`.
3. При переходе с совместимой Qt Beta / RC используйте «Проверить обновление» либо установите ZIP вручную. Перед ручной заменой сохраните резервную копию пользовательских JSON.
4. Для восстановления ярлыка запустите `Update DBD Randomizer Shortcut.cmd` из папки приложения.

## Контроль качества

Windows CI проверяет генерацию и 20 аддонов Доктора, уникальные испытания, Qt/QML интерфейс, Python тесты, ZIP/EXE, SHA-256 и сценарий обновления RC1 → v3.0.0 с сохранением пользовательских данных. Пользователь подтвердил проведение тестирования в предыдущих обсуждениях.

**Примечание:** встроенные данные о переводах скинов содержат английские оригиналы для элементов без подтверждённого русского названия. Работоспособность автоматизации зависит от координат и настроек конкретного ПК — перед вводом проверьте сухой прогон.
