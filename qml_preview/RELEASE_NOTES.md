# DBD Ultimate Search Randomizer — Qt Beta 4

Обновление новой версии на **PySide6 + QML**, сделанное по отзывам о билдах, аддонах и челленджах.

## Исправлено

- **Аддоны больше не показываются только картинками.** Для каждого из двух слотов — отдельная карточка с иконкой, номером и настоящим названием аддона из базы игры. Длинные названия переносим и показываем целиком при наведении.
- **Челленджи подробно объясняются.** Отдельная карточка показывает заголовок, сложность, полное русское условие, пояснение и запреты на предметы, навыки или аддоны. Тексты берутся из исходной базы челленджей, без придуманных эффектов.
- Кнопка «Другой челлендж + билд» пересоздаёт билд с учётом новых ограничений.
- Убраны старые тестовые надписи об отсутствии игровых данных.

## Продолжение редизайна

- Конструктор билдов теперь предлагает **визуальные каталоги с картинками и поиском**: персонажи, навыки, аддоны и предметы выживших.
- При выборе предмета для выжившего список аддонов ограничивается совместимыми с ним, для маньяка — аддонами выбранной силы.
- Проверка конструктора не пропускает неизвестные, несовместимые или повторные аддоны.
- Сохранены отдельные колонки маньяков/выживших и галерея скинов с настоящими портретами из Beta 3.

## Как обновиться

Если установлена **Qt Beta 3**, нажмите «Проверить обновления» в новом Qt-интерфейсе. Обновление с проверкой SHA-256 можно установить оттуда.

Если установлен только **старый Tkinter EXE v2.28.0**, его кнопка не сможет автоматически заменить интерфейс. Скачайте Qt Beta 4 вручную и положите рядом с `dbd_randomizer_config.json`, предварительно сохранив копию старой папки.

Изображения из wiki.gg могут потребовать интернет при первой загрузке, затем используются из локального кэша.

## Ограничения

Это предварительный релиз. CI проверяет Python-код, генератор, Qt, сборку и запуск Windows EXE, но не реальную экипировку внутри DBD. Перед автоэкипировкой проверьте координаты и стоп-клавишу F9 и начните с сухого прогона. Полных описаний игрового эффекта каждого аддона в текущей базе пока нет: на карточках показываются **точные названия**, без выдуманных описаний.
