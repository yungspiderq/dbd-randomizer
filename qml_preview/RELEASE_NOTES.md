# DBD Ultimate Search Randomizer — Qt Beta 3

Обновление интерфейса на **PySide6 + QML**, исправления по отзывам о разделе «Персонажи» и галерее внешности. Оригинальная стабильная версия v2.28.0 сохранена.

## Главное в Beta 3

- **Раздел «Персонажи» снова разделён на две колонки:** маньяки и выжившие. Счётчики, поиск, отметки владения, массовые действия «Все», «Никого» и «Инверсия» работают отдельно.
- **Настоящие портреты персонажей** из оригинального источника, с автоматической загрузкой и локальным кэшем.
- **Раздел «Внешность» переработан в полноценную галерею:** выбор героя с портретом, списки с миниатюрами скинов, большое превью, редкость, дата, поиск по RU/EN названию, случайный набор и быстрый выбор владения.
- Исправлена совместимость со старыми настройками владения: ранее не отмеченные явно скины по умолчанию считаются доступными (как в Tkinter).
- На карточке билда отображаются изображения персонажа, предмета/силы и аддонов; перки с иконками.
- Нет скрытого окна Tkinter, основная логика использует самостоятельный Qt backend, а игровые данные и генератор берутся из оригинального Python-проекта.
- Проверки регрессионных тестов, QML и сборки Windows EXE в GitHub Actions.

Изображения wiki.gg скачиваются по требованию и сохраняются в `icons_cache`: первый просмотр требует интернета. Если изображение недоступно, будет аккуратная заглушка.

## Переход с предыдущей версии

- **Из старого Tkinter EXE кнопка «Проверить обновления» не установит Qt.** Новую Qt-версию нужно скачать и запустить вручную один раз.
- **Из Qt Beta 2** можно нажать «Проверить обновления» — должна предложить Beta 3 через GitHub Releases с проверкой SHA-256.
- Поместите EXE рядом с `dbd_randomizer_config.json` для сохранения координат и настроек. Перед первым запуском сохраните копию папки.

## Ограничения Beta

Проверки Windows CI не заменяют реальную проверку автоэкипировки в Dead by Daylight. Сначала используйте «Сухой прогон» и проверьте F9. Это предварительный выпуск, не замена стабильной версии для всех пользователей.
