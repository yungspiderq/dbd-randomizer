# DBD Ultimate Search Randomizer — Qt Beta 17

## Определение запущенной DBD по процессу

- Убрана зависимость от заголовка окна «Dead by Daylight», который мог отсутствовать или отличаться.
- Игра определяется по **DeadByDaylight-Win64-Shipping.exe** (поддержан также WinGDK-Shipping.exe), а не по лаунчеру или имени окна.
- Включение фокуса теперь находит окно по PID процесса, а проверка перед кликом подтверждает, что активен именно процесс DBD. Это предотвращает ошибочные клики в другие программы.
- Добавлены Windows-регрессионные тесты для совпадения процесса, неверного лаунчера и окна без заголовка.

## Обновление без загадочных перезапусков

- В разделе «Обновления» виден фактический прогресс загрузки ZIP по шагам 10%.
- После загрузки отдельно отображаются сверка размера и SHA-256, безопасная распаковка и передача управления установщику. Больше не выглядит так, будто приложение немедленно перезапустилось, пока оно ещё скачивает большой архив.
- На ошибки скачивания UI отвечает понятным текстом, не скрывая доступное обновление.
- При следующем запуске показывается установленная версия Beta 17; ошибки PowerShell и ход установки по-прежнему доступны в `dbd_update_error.log` и `dbd_update_progress.log`.

## Контроль качества

- Python-тесты проверяют корректное состояние `updateBusy` и `updateAvailable` во время загрузки, порядок сообщений прогресса и проверку SHA-256.
- Windows CI проверяет сборку Qt, все регрессионные тесты, запуск portable EXE, целостность ZIP и установку через настоящий PowerShell-скрипт.
- Перед публикацией Beta 17 CI дополнительно скачивает официальный архив Beta 16, устанавливает локально собранную Beta 17 поверх него, проверяет запущенный новый EXE, файлы runtime и сохранность пользовательских JSON.

## Ограничения

Эта версия остаётся **Pre-release**. Автоматизированная установка проверена в изолированной Windows-среде; перед стабильным выпуском нужен ручной тест на реальном ПК, включая взаимодействие с DBD. Для перехода со старых Beta 12–15 при проблемах с автообновлением можно один раз вручную распаковать новый portable ZIP в отдельную папку, сохранив пользовательские настройки.
