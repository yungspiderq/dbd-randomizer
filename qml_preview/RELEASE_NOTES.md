# DBD Randomizer Qt v3.2.0 — Companion

**Канал:** Stable · **ОС:** Windows

- Новый раздел «Анализатор билдов»: категории навыков, известные сочетания, предупреждения об истощении, несовместимых аддонах и неполных билдах. Правила ручные и не являются прогнозом победы.
- Новый раздел «Энциклопедия DBD»: маньяки, выжившие, навыки, аддоны и предметы из локального каталога. Поиск без пунктуации, страницы результатов, иконки, владельцы навыков, доступные описания и ссылки на Wiki.
- Исправление поиска «Дар», «Чары» и «Секущий крюк» из v3.1.3, включая сохранение официальных названий.
- Сохранены существующие настройки, избранное и история. Проверка обновления с опубликованной v3.1.2.

Полнота описаний зависит от встроенного каталога; новые персонажи главы Terrifier пока не включены.
