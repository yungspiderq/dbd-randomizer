# DBD Ultimate Search Randomizer — Qt Beta 22

## Галерея внешности: русские названия и проверка источника

- Галерея показывает для каждого набора **русское имя, если оно есть**, исходное английское название и основание сопоставления: по изображению на русской вики, по деталям, через другой набор или сохранённое из предыдущей базы.
- Добавлен переключатель «Все названия / С RU / Без RU». Он фильтрует только отображение и **не меняет** сохранённые отметки владения и шансы выпадения.
- Для каждого персонажа показывается количество наборов с RU-названиями и без них, а в подробной карточке — откуда взято название.
- При переходе из галереи выживших к убийцам (и обратно) корректно меняется выбранный персонаж.
- Поиск по-прежнему понимает как русское, так и английское название.

## Проверка данных

- Аудит `tools/catalog_audit.py` теперь проверяет не только владельца и сторону косметического ID, но и признаки смены самого набора в пределах одного персонажа. Такой случай блокирует автоматическое обновление до ручной проверки.
- В Windows CI выполняются дополнительные регрессионные тесты полноты локализации и сохранности ID.
- Используется актуализированная в Beta 21 база косметики `10.2.2_live`: **2 250** записей, **1 663** с русским названием. Для **587** записей русское имя в наших источниках ещё не подтверждено.
- Названия навыков и аддонов продолжают проходить проверку полноты внутренней RU-карты, но *совпадение каждой строки с реальным игровым клиентом* не подтверждается этой проверкой. Автоматические вымышленные переводы не добавляются.

## Сборка и установка

- Версия: `v2.28.0-qt-beta.22`.
- Windows CI проверяет Qt/QML, EXE, ZIP, SHA-256 и полное обновление **Beta 21 → Beta 22** с сохранением пользовательских данных.
- Обязательная проверка имени процесса Dead by Daylight не возвращалась. Остановка по потере фокуса и F9 остаются.
- GitHub Pre-release не является стабильной версией; проверка автоэкипировки в настоящей игре всё ещё нужна перед Stable.
