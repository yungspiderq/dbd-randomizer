# DBD Ultimate Search Randomizer — Qt Beta 2

Новый интерфейс PySide6 + Qt Quick с собственными элементами управления и без скрытого окна Tkinter. Генератор пользуется оригинальными данными и правилами v2.28.0.

## Что перенесено

- Генерация билдов обеих сторон, режимы и списки доступных персонажей, аддоны, предметы, навыки
- Карточки навыков с иконками, копирование, фиксация и переброс; классы 2v8, челенджи и внешность
- Конструктор пользовательского билда с проверкой навыков
- Билды сообщества: просмотр, копирование, загрузка и публикация через Firebase
- Сохранение совместимых настроек в dbd_randomizer_config.json, координаты, тайминги и OCR
- Автоэкипировка на прежнем DirectInput-движке, сухой прогон, прерывание F9, буфер обмена, повторные поиски
- Проверка следующих Qt-релизов из интерфейса и установка только с проверкой SHA-256 (для Windows EXE)
- Функции базы данных и журнал; SVG/векторные элементы интерфейса без эмодзи

## Важно: первое обновление со старой версии

Установленная v2.28.0 на Tkinter **не сможет автоматически установить новую Qt-версию**:
в режиме EXE её кнопка проверки обновлений лишь сообщает, что релиз нужно скачать вручную.
Скачайте этот EXE один раз из Releases и поместите его в каталог старой программы рядом с
dbd_randomizer_config.json, чтобы сохранить координаты и настройки. Сначала создайте копию
папки на всякий случай; старый DBDRandomizer.exe не удаляйте.

Следующие Qt beta релизы можно искать через кнопку «ПРОВЕРИТЬ ОБНОВЛЕНИЯ» внутри новой версии.

## Ограничения

Это предварительный выпуск. Windows CI проверяет запуск Qt, генерацию и регрессионные тесты,
но автоэкипировка ещё не протестирована **в настоящей игре** на разных разрешениях. Перед
реальным запуском проверьте координаты, настройте стоп-клавишу и используйте сухой прогон.
Не раздавайте GitHub-токены; публикация через Firebase не требует токена.
