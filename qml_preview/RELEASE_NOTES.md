# DBD Ultimate Search Randomizer — Qt Beta 7

## Новое: отдельный режим «Сбалансированная ротация»

Оригинальный режим случайного выбора сохранён без изменений. Новый режим включается переключателем **«Обычный / Сбалансированный»** на вкладке «Билд».

- Выбранный маньяк или выживший получает сниженный вес при следующих генерациях.
- Часто появлявшиеся персонажи постепенно уступают шанс тем, кто выпадал редко; веса восстанавливаются относительно статистики и давности.
- Сходный алгоритм действует для навыков, аддонов, категорий и предметов выживших.
- Для каждого маньяка и каждой категории предметов хранится собственная статистика аддонов.
- Настройки перков, списки доступных персонажей, ограничения челленджей и включённые фильтры сохраняют приоритет.
- Повторы всё ещё возможны — это случайный выбор с весами, а не фиксированная очередь. Никто не исключается навсегда.
- История сохраняется в обычном конфиге и продолжает работать после перезапуска; маньяки и выжившие учитываются отдельно.
- Показано, сколько различных персонажей участвовало в ротации. Кнопка «Сброс истории» требует подтверждения и обнуляет только текущую роль.

## Значок приложения

Добавлена **иконка** для окна Qt, панели задач Windows, бокового меню и EXE (многоразмерная `.ico`). Исходный векторный логотип хранится в `qml_preview/assets/app_icon.svg`; отдельный исходный PNG можно положить как `qml_preview/assets/app_icon_source.png` — сборщик использует его вместо векторного по умолчанию.

## Совместимость

Beta 7 — предварительный релиз. Предыдущие функции (подписанные аддоны, описание челленджей, каталог скинов, визуальный конструктор, короткие проверенные справки по эффектам) сохранены. Windows CI проверяет оригинальный генератор, статистическую ротацию, конфигурацию, QML, сборку и запуск готового EXE.

Автоэкипировка напрямую в Dead by Daylight на разных системах ещё требует ручной проверки: сначала сухой прогон и проверка стоп-клавиши F9.

Из Qt Beta 6: «Проверить обновления» → установка нового EXE после SHA-256. Из старой Tkinter v2.28.0: первая установка вручную из GitHub Releases; сохраните копию прежней папки.
