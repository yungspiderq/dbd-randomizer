# DBD Randomizer Qt v3.0.4 Stable — корректная высота карточек

**Версия:** `v3.0.4` · **Stable** · обновление с v3.0.3.

## Исправлено

- **Классы 2v8:** описания навыков больше не выходят за пределы карточек и не перекрывают соседний класс или кнопку копирования. Карточка автоматически расширяется на всю высоту текста, а страница прокручивается.
- **Аддоны:** длинные названия и отметки запрета больше не перекрываются и не обрезаются без необходимости.
- **Избранное:** длинные заметки полностью отображаются; дата сохранения и кнопки автоматически размещаются ниже.
- **Статистика, настройки, режим рандомизатора:** карточки с многострочными текстами учитывают реальную высоту содержимого.
- **Подписи кнопок и строк каталогов:** элементы не накладываются друг на друга. Если подпись кнопки слишком длинная, её можно посмотреть целиком по наведению.

## Проверено

Windows CI: регрессионные тесты Qt, реальный запуск QML на узком и обычном размере окна с заведомо длинными описаниями, EXE, ZIP + SHA-256 и обновление v3.0.3 → v3.0.4 с сохранением пользовательских данных.

**Установка:** «Проверить обновления» в v3.0.3 либо полный архив `DBDRandomizerQtBeta.zip`. Название ZIP/EXE сохраняется для совместимости со старым обновлятором.
