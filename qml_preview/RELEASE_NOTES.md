# DBD Randomizer Qt v3.1.3 — поиск даров и чар

**Канал:** Stable · **ОС:** Windows

- При автоэкипировке навыки «Дар», «Чары» и «Секущий крюк» вводятся без знаков препинания.
- Например: «Дар: круг исцеления» → «дар круг исцеления».
- Поиск в конструкторе Qt принимает названия с пунктуацией и без неё.
- Названия в каталоге, сохранённых билдах и настройках остаются прежними.
- Добавлены регрессионные тесты; публикация после Windows CI и проверки обновления с v3.1.2.

Новые персонажи главы 10.3.0 в этот исправляющий релиз не включены.
