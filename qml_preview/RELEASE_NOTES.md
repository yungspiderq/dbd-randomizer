# DBD Ultimate Search Randomizer — Qt Beta 21

## Актуальная база наборов одежды и обликов

- Обновлена база внешности по wiki.gg (снимок `10.2.2_live`, 20 октября 2026): **2 250** наборов и обликов, в том числе 119 обликов персонажей.
- Из русскоязычной вики обновлены названия наборов. В каталоге теперь **1 663** записи с RU-названиями против 1 620 в Beta 20 (**+43**). Для 587 неподтверждённых переводов сохранены исходные английские имена вместо выдуманных русских.
- Поддержана стабильность локальных ID при перенумерации записей wiki.gg: ранее сохранённые отметки владения не должны переназначаться на чужие наборы.
- Персонажи, присутствующие только в будущих PTB, не добавляются в текущую игровую базу.

## Проверка навыков и аддонов

- Добавлен воспроизводимый аудит `tools/catalog_audit.py`: проверка структуры и внутренних соответствий RU-названий для всех 144 навыков убийц, 176 навыков выживших и справочников аддонов.
- В проверенной версии внутренних таблиц нет пропущенных сопоставлений названий перков с иконками и аддонов с RU→EN.
- **Важно:** внутренняя проверка базы не доказывает буквальное совпадение каждого имени с русской локализацией текущего клиента DBD. Точные названия и 587 недостающих переводов требуют дальнейшего подтверждения по игровому клиенту или достоверным источникам.
- Человекочитаемый отчёт: `tools/catalog_audit.md`. Машинный отчёт: `tools/catalog_audit.json`.

## Проверки Windows и обновления

- Версия: `v2.28.0-qt-beta.21`.
- Windows CI выполняет регрессионные тесты Qt/QML и автообновления, сборку portable ZIP с SHA-256 и E2E-обновление **опубликованной Beta 20 → кандидат Beta 21** с сохранением пользовательских файлов.
- Автоэкипировка продолжает использовать ручной выбор активного окна и F9, без обязательной проверки процесса DBD.
- Выпуск публикуется исключительно как **GitHub Pre-release** после успешной сборки.

Это предварительная версия. Тесты GitHub Actions не заменяют реальную проверку экипировки в Dead by Daylight на компьютере пользователя.
