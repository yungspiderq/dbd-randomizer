# Qt Release Candidate 1 — план реального тестирования (Windows 11)

> Версия-кандидат: `v3.0.0-qt-rc.1`. Проверки CI **не подтверждают**, что автоэкипировка действительно работает в Dead by Daylight. До завершения этого плана Stable не выпускается.

## 0. Установка без риска потерять Beta 22

1. В GitHub Actions RC1 скачайте артефакт `DBDRandomizerQtRC1-Portable-Windows` после успешной сборки. ZIP внутри по-прежнему называется `DBDRandomizerQtBeta.zip` — это техническая совместимость с установщиком.
2. **Не распаковывайте архив поверх текущей Beta 22.** Распакуйте в отдельный каталог, например `DBD-RC1-Test`.
3. Скопируйте туда **копии** `dbd_randomizer_config.json`, `dbd_database.json`, пользовательских файлов и при необходимости `icons_cache` из установленной папки. Оригинальные файлы Beta 22 не трогайте.
4. Проверьте запуск `DBDRandomizerQtBeta.exe`. Подтвердите, что заголовок показывает **Qt RC 1**.
5. Из постоянной папки RC1 откройте `Update DBD Randomizer Shortcut.cmd` двойным щелчком. Дождитесь сообщения об успехе. Откройте ярлык «DBD Randomizer» с рабочего стола — он должен запускать **Qt RC 1**, а не старую Tk-программу. Не запускайте этот файл из временной папки, которую собираетесь удалить.
5. Сравните настройки, избранное, отметки владения скинами и конструктор билдов с Beta 22.

**Важно для перехода Beta 22 → RC 1:** установленный обновлятор Beta 22 умеет находить только теги `-qt-beta.N`. Поэтому кнопка «Проверить обновления» в Beta 22 **не увидит** настоящий тег `-qt-rc.1`. Пока для тестирования используется отдельный ZIP. Прежде чем делать общедоступный RC с автообновлением, понадобится совместимый переходный Beta-релиз или иной проверенный путь миграции. Новый обновлятор RC 1 уже распознаёт Beta / RC / Stable.

## 1. Быстрые проверки интерфейса (вне игры)

- [ ] Программа запускается и закрывается без зависших процессов.
- [ ] Ярлык «DBD Randomizer» указывает на EXE из папки RC1, имеет актуальную иконку и запускает Qt RC1.
- [ ] Быстрое изменение размера окна не вызывает длительных зависаний.
- [ ] Масштаб 100%, 125% и 150%: кнопки и панели доступны.
- [ ] Выжившие и убийцы отображаются раздельно; поиск и конструктор работают.
- [ ] Галерея: фильтры «С RU / Без RU», изображения и сохранённые отметки работают.
- [ ] Сохранённый билд, история, избранное, настройки и координаты не изменились сами по себе.
- [ ] Открывается журнал; сообщение об ошибке понятно.

## 2. Автоэкипировка непосредственно в DBD — обязательный блок

Перед тестами используйте **тестовый билд** и включите режим «Сухой прогон», затем проверьте с реальными действиями в меню игры.

- [ ] Координаты `search`, `first_result`, `slot1..slot4` соответствуют текущим настройкам экрана.
- [ ] В «Сухом прогоне» нет реальных кликов по игре.
- [ ] Нажмите «Экипировать в игре», вручную переключитесь в DBD во время отсчёта: окно захватывается **без проверки имени EXE**.
- [ ] Перки правильно ищутся и выбираются **во всех четырёх слотах**, без перепутанных предметов.
- [ ] Если нажать **F9** во время отсчёта, никакие клики не происходят.
- [ ] Если нажать F9 во время выполнения, следующие действия прекращаются.
- [ ] Если переключиться в другое окно во время экипировки, отправка последующих действий прекращается.
- [ ] Если не переключиться в DBD к концу отсчёта, приложение не кликает по собственному окну.
- [ ] Если пропадает результат поиска или задана некорректная координата, появляется понятная ошибка; никаких случайных кликов.
- [ ] Проверьте поведение при масштабе Windows != 100% и при другом разрешении, **повторно калибруя координаты**.
- [ ] Проверьте включённую OCR-проверку только после настройки области распознавания.
- [ ] После неудачного выполнения приложение не сообщает, что неизвестный результат «успешно экипирован».

Не тестируйте одновременно с другой программой, перехватывающей клавиатуру/мышь. Для оперативной остановки используйте F9; если глобальная клавиша не зарегистрировалась, не начинайте реальные клики до устранения ошибки.

## 3. Проверки обновления и сохранности данных

- [ ] Тестовый ZIP запускается отдельно от Beta 22.
- [ ] Изменения в избранном, истории, настройках, `dbd_database.json` и выбранных скинах сохраняются после перезапуска.
- [ ] После публикации совместимого пути обновления: проверить настоящий переход Beta 22 → RC 1 на своём ПК.
- [ ] Проверить сообщение о неполном ZIP/ошибке SHA-256 и возможность остаться на старой версии.
- [ ] Проверить отсутствие временных папок, оставшихся процессов и потерянных пользовательских файлов.
